````
| Feature | TCP (Transmission Control Protocol) | UDP (User Datagram Protocol) |
|---------|--------------------------------------|------------------------------|
| **Connection** | Connection‑oriented (handshake) | Connection‑less |
| **Reliability** | Guarantees delivery, ordering, and error‑checking; retransmits lost packets | No guarantees; packets may arrive out of order, duplicated, or lost |

| **Use Cases** | Web browsing (HTTP/HTTPS), email, file transfer, SSH | Streaming media, online gaming, DNS, VoIP |
| **Flow Control** | Yes (window size, congestion control) | No |
````

````
### Closure in JavaScript

A **closure** is a function that **remembers** the variables from the scope where it was **created**, even after that outer function has finished executing.

#### How it works
1. When a function is defined, JavaScript creates a *lexical environment* that contains all variables in its surrounding scope.  
2. If the inner function references any of those variables, it forms a closure over them.  
3. The inner function keeps a reference to that environment, so the variables stay alive as long as the closure can be reached.

#### Common uses
- **Data privacy / encapsulation** – simulate private variables.  
- **Partial application / currying** – pre‑fill some arguments.  
- **Event handlers / callbacks** – retain context between async calls.

#### Simple example
```javascript
function makeCounter() {
  let count = 0;               // ← outer variable
  return function () {        // ← inner function (closure)
    count += 1;
    return count;
  };
}

const counter = makeCounter(); // `makeCounter` finishes, but its scope lives
console.log(counter()); // 1
console.log(counter()); // 2
```

Here, the returned function still accesses `count` even though `makeCounter` has already returned. That's the closure in action.
````

````
A **closure** in JavaScript is a function that remembers and can access variables from the scope in which it was created, even after that outer function has finished executing.

In simple terms, it’s a function that “closes over” its local scope.

### How It Works
1. A function is defined inside another function.
2. The inner function references variables from the outer function.
3. The inner function is returned or used elsewhere.
4. The inner function still has access to those variables, even though the outer function has exited.

### Basic Example

```javascript
function outer() {
  const secret = 42;

  function inner() {
    return secret;
  }

  return inner;
}

const getSecret = outer();

console.log(getSecret()); // 42
```

Here, `inner()` is a closure because it remembers `secret` from `outer()`, even after `outer()` has finished running.

### Key Points
- Closures preserve the **environment** of the function where they were created.
- They keep variables alive in memory as long as the closure exists.
- They’re commonly used for:
  - Encapsulation (private variables)
  - Function factories
  - Callbacks and event handlers
  - Maintaining state across invocations

Closures are a core part of JavaScript’s and are widely used in patterns like module design, memoization, and stateful utilities.
````

````
القانون العام لحل المعادلة التربيعية هو أداة رياضية قوية تتيح لنا إيجاد جذري أي معادلة من الدرجة الثانية.

### **الخلفية التاريخية**
اشتُق هذا القانون في الأصل لتحليل الدوال التربيعية وإيجاد جذورها. على الرغم من أن mathematicians قدامى مثل دياوفانتوس تناولوا مسائل مثل $ ax^2 + bx + c = 0 $، إلا أن الصيغة العامة المعروفة اليوم تم التأكيد عليها وتطويرها بشكل رئيسي في القرن السادس عشر.

### **الصيغة الرياضية**
المعادلة التربيعية العامة هي:
$$ ax^2 + bx + c = 0 $$
حيث:
*   $ a, b, c $ هي ثوابت (أرقام محددة).
*   $ a \neq 0 $ (لأنه إذا كان $ a = 0 $، تصبح المعادلة خطية وليسًا تربيعية).
*   $ x $ هو المجهول الذي نريد إيجاد قيمته.

جذرا هذه المعادلة (أي قيم $ x $ التي تحقق المعادلة) يعطيان بواسطة القانون العام:

$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$

### **فهم الأجزاء (المميز)**
الجزء الموجود داخل الجذر التربيعي، وهو $ b^2 - 4ac $، يُسمى **المميز** (Discriminant) وغالباً يُرمز له بالرمز $ \Delta $.
قيمة المميز تحدد طبيعة الجذرين:

1.  **إذا كان $ \Delta > 0 $:**
    *   تكون هناك **جذران حقيقيان مختلفان**.
    *   $ x_1 = \frac{-b - \sqrt{\Delta}}{2a} $
    *   $ x_2 = \frac{-b + \sqrt{\Delta}}{2a} $

2.  **إذا كان $ \Delta = 0 $:**
    *   يكون هناك **جذر حقيقي مميز** (جذران متطابقان).
    *   $ x = \frac{-b}{2a} $

3.  **إذا كان $ \Delta < 0 $:**
    *   تكون هناك **جذران مركبان** (تخيليان) متتاليان، لأننا لا نستطيع سحب جذر تربيعي لعدد سالب في مجال الأعداد الحقيقية.
    *   $ x = \frac{-b \pm i\sqrt{-\Delta}}{2a} $
    *   (حيث $ i $ هي الوحدة التخيلية $ \sqrt{-1} $).

### **مثال تطبيقي بسيط**
لنعطِ مصداقية لهذه النظرية، لنحل المعادلة التالية:
$$ x^2 - 5x + 6 = 0 $$

هنا: $ a = 1, b = -5, c = 6 $.

1.  نحسب المميز $ \Delta $:
    $$ \Delta = (-5)^2 - 4(1)(6) = 25 - 24 = 1 $$

2.  بما أن $ \Delta > 0 $، فله جذران حقيقيان مختلفان:
    $$ x = \frac{-(-5) \pm \sqrt{1}}{2(1)} $$
    $$ x = \frac{5 \pm 1}{2} $$

3.  بالنتيجة نحصل على:
    *   $ x_1 = \frac{5 + 1}{2} = \frac{6}{2} = 3 $
    *   $ x_2 = \frac{5 - 1}{2} = \frac{4}{2} = 2 $

النتيجة النهائية هي أن جذري المعادلة هما **3** و **2**. وهذا يتطابق مع ما نحصل عليه بالتحليل ($ (x-3)(x-2)=0 $).
````
