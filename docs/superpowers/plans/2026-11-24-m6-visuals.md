# M6 Visuals Implementation Plan

**Goal:** Replies can carry charts, diagrams and step-throughs that render inline, themed, RTL-correct, and never shift the text while streaming.

**Architecture:** Visuals are fenced blocks inside the Markdown (`chart`, `mermaid`, `stepper`; `html` as Tier 2). `Markdown` routes visual fences to a `Visual` component instead of a code block. While a fence is still open the row shows a sized placeholder; once closed the spec is validated with Zod (Mermaid with `mermaid.parse`) and rendered. Anything invalid falls back to the source as a code block.

**Spec:** `docs/architecture.md` §5 step 7, §7 placeholders, §9 Visuals, §10 RTL, §11 lazy-loading.

## Decisions

- **Charts are our own SVG** (bar, line, donut), not Chart.js: theme tokens and RTL for free, motion consistent with the app, zero bundle cost. `ponytail:` add a library only if we need scatter/stacked/axes beyond this.
- **Mermaid is lazy-loaded** on the first diagram, themed from CSS tokens (`base` theme + `themeVariables`).
- **Numbers** use `Intl.NumberFormat` with Western digits in both locales (`ar-u-nu-latn`), matching how the model writes them.
- **Tier 2 `html`**: `iframe sandbox="allow-scripts"` (never `allow-same-origin`), `srcdoc`, CSP `default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; img-src data:`; height reported by an injected script via `postMessage`, accepted only from that iframe, capped at 600px.

## Global constraints

- Model-written HTML never enters the main document.
- Placeholders reserve the final height (chart 18rem, diagram 20rem, stepper/html 14rem) so nothing jumps.
- Every visual has a text alternative: charts expose a visually hidden data table; diagrams keep their source behind a "Show source" toggle.
- Copy via `better-writing`; Arabic natural and dialect-neutral.

## Tasks

1. **Visual routing + chart + stepper**: fence detection in `Markdown` (closed vs open), `Visual`, `Chart` (bar/line/donut, Zod spec), `Stepper`, placeholder, fallback. Test: spec parsing (valid, invalid → null) and fence-closed detection.
2. **Mermaid**: lazy import, parse-then-render, themed, source toggle, fallback.
3. **Tier 2 html sandbox**: `SandboxFrame` with CSP + height messages.
4. **Prompt + mock**: system prompt decision guide (text by default; chart for numbers; mermaid for flows; stepper for sequences; html only when nothing else fits). Mock answer streams one of each.
5. **Verify and ship**: real Gemini prompts that should and shouldn't produce visuals, in Arabic and English; dark/light; 375px; deploy.
